# 해운대 해양안전 AI

해운대 방문객이 위험 해양 생물 출몰 정보를 확인하고, 사진을 분석하고, 발견 위치를 제보할 수 있도록 만든 모바일 웹앱입니다.

## GitHub Pages

이 저장소의 `index.html`을 GitHub Pages로 공개할 수 있습니다.

## 주의

- AI 분석, 제보 저장, 관리자 인증은 별도로 배포한 FastAPI 서버가 필요합니다.
- `best.pt`, 환경변수, 사용자 제보 사진과 개인 정보는 이 저장소에 포함하지 않습니다.
- AI 분석 결과는 추정 결과이며 의료적 진단이 아닙니다.
- 응급 상황에서는 119 또는 현장 안전요원에게 연락하세요.
